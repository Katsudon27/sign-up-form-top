# Project: Sign Up Form

This is a project completed as part of The Odin Project with the main objective of building a Sign Up Form to demonstrate the following skills/concepts:
- CSS Resets
- CSS Units
- Usage of external fonts
- Text styles (i.e. letter spacing and line height)
- Usage of advanced selectors (i.e. child, attribute, pseudo-classes etc.)
- Positioning of elements
- Usage of form controls
- Client-side input validation for form controls
